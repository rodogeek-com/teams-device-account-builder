# RodoGeek Teams Device Account Builder

A bilingual, local-first tool for generating Microsoft Teams device
account configurations and review-ready PowerShell.

## Supported device types

- Microsoft Teams Rooms on Windows
- Microsoft Teams Rooms on Android
- Microsoft Teams Panels
- Common Area Phones
- SIP Devices

## Privacy

The application runs entirely in the browser.

It does not:

- Connect to a Microsoft 365 tenant
- Execute PowerShell
- Send form data to a server
- Store generated passwords

Administrators must review and execute the generated PowerShell
manually.

## Usage

1. Select a device type.
2. Enter the room or device information.
3. Review the generated naming convention.
4. Confirm the suggested licensing information.
5. Copy or download the PowerShell script.
6. Review the script before execution.
